# HS Shot

macOS専用のスクリーンショット・注釈アプリです。SwiftUI / AppKitで実装しています。

## ダウンロード・使い方

**[HS Shotの配布ページ](https://hs-shot-download.kaiyamucun526.chatgpt.site)** に、Mac版のダウンロード、インストールと画面収録権限の設定、操作ガイドをまとめています。アカウント登録なしで閲覧でき、社内でURLを共有できます。

操作ガイドは約85秒、日本語音声・字幕つきです。範囲撮影、左下の固定プレビュー、注釈、履歴保存、PNG/JPEG書き出しを順番に説明しています。実機の静止画と、範囲選択の操作を示す説明図で構成しています。連続した画面録画ではありません。

## 起動

[GitHub Releases](https://github.com/kaiamucun/HS_Shot/releases) から最新のPKGをダウンロードし、インストーラを開くと `/Applications/HS Shot.app` に配置されます。リポジトリとReleaseは公開されています。

ローカルでビルドした場合は `dist/HS Shot.app` を開いてください。

- macOS 14以降。ビルドスクリプトはApple Silicon / Intel両方に対応するUniversalアプリを作成します。
- 初回の撮影時に、macOSの「画面収録」権限が必要です。設定画面の案内からHS Shotを許可し、アプリを再起動してください。
- アプリは開発用のローカル署名、PKGは署名なしです。Developer ID署名・Appleの公証は行っていないため、macOSで起動やインストールの確認が出る場合があります。
- 白と淡いグレーを基調に、操作ボタンを落ち着いた青で表示します。編集キャンバスとフローティングプレビューも同じライトテーマです。

## 撮影から編集まで

1. **範囲を選択**、または **⌘⇧2** で撮影します。Escでキャンセルできます。
2. 撮影画像が**左下に210×150ポイント固定のサムネイルで表示**されます。画像の縦横比を保って枠内に収めます。自動では消えません。直近4枚まで重ねて表示します。
   マウスを重ねると背景がぼけ、中央に**コピー・保存**、隅に**閉じる・ピン留め・編集**が現れます。
3. **画像自体をクリック**、または **編集** でエディタを開きます。
4. 矢印、線、四角形、楕円、ペン、ハイライト、文字、連番、ピクセル化、塗りつぶし秘匿、切り抜きを使えます。
5. **選択ツール**で注釈をクリックして選び、ドラッグで移動、Deleteで削除できます。⌘Zで取り消します。
6. **コピー**で貼り付け用の画像を取得、**書き出す**でPNG/JPEG、**ライブラリに保存**で履歴へ保存します。編集した画像は原本とは別の項目になります。

文字は画像をクリックして入力し、Enterで確定、Escで取り消し。色と線幅は右側で選べます。背景・余白も追加できます。選択やツールの切り替えはキャンバスにフォーカスがあるとき、V（選択）、A（矢印）、R（四角形）、T（文字）、B（ペン）、H（ハイライト）、C（切り抜き）が使えます。

フローティング画像はほかのアプリへドラッグできます。コピー・ファイル保存・最前面へのピン留めもプレビューから操作できます。メインウィンドウを閉じてもメニューバーから使えます。アプリ全体の終了は⌘Qです。

## その他の機能

| 操作 | ショートカット |
| --- | --- |
| 範囲を選択して撮影 | ⌘⇧2 |
| 画面全体を撮影（メインディスプレイ） | ⌘⇧6 |
| ウィンドウを撮影 | ⌘⇧7 |
| 選択範囲から文字を認識 | ⌘⇧8 |
| 画面録画を開始・停止 | ⌘⇧9 |

- **タイマー**：3秒 / 5秒 / 10秒。
- **履歴**：検索、お気に入り、再編集、コピー、書き出し、Finder表示。画像・動画を読み込み可能。
- **OCR**：Visionによる日本語・英語の文字認識。結果を確認して全文コピー。
- **ピン留め**：最前面表示、サイズ・不透明度変更。
- **録画**：カーソルのあるディスプレイをMP4へ録画。システム音声は設定で追加可能。H.264互換性のため長辺最大4096px。停止後に保存処理を行います。
- **スクロール結合**：同じ幅の範囲を、前の画像と1/3程度重なるように順次撮影します。ページ移動は手動です。「結合して編集」で1枚にまとめます。重なりを判断できない画像、固定ヘッダー、アニメーションが多い画面などではエラーになる場合があります。

## 保存とプライバシー

保存先は `~/Library/Application Support/HS Shot/` です。画像・動画と `library.json` をまとめてバックアップできます。

**クラウド機能、外部アップロード、利用状況の送信はありません。** OCRもMac内で処理します。撮影後は自動保存され、ファイルへの書き出しは保存先を指定して行います。画像を自動でクリップボードにコピーする設定はオフにできます。

機密部分を隠す場合は「塗りつぶし秘匿」を使用してください。書き出し画像の該当部分を不透明な黒で描画します。元画像はライブラリに残るため、共有する際には編集済みの出力画像を選んでください。

## ビルド・テスト

Xcodeのコマンドラインツールが必要です。外部パッケージの取得はありません。

```sh
swift test --build-system native
./scripts/build-app.sh
./scripts/build-pkg.sh
open "dist/HS Shot.app"
```

SwiftPMプロジェクトなので `Package.swift` をXcodeで開いて開発できます。エントリポイントは `Sources/HSShot/main.swift` です。

開発用署名のため、再ビルド後に画面収録権限の再登録が必要になる場合があります。設定上はオンでもアプリが未許可と表示する場合は、システム設定の画面収録一覧から古いHS Shotの項目を外し、更新した `.app` を追加してアプリを再起動してください。

テストは履歴の保存・復元、画像寸法、OCR、スクロール結合、注釈の実ピクセル出力、秘匿、取り消し、録画ファイルのエンコードと終了処理を対象とします。実機での画面選択・録画はmacOSの許可が必要です。Intelの実機検証は行っていません。

## 配布サイト・操作ガイドの制作

配布サイトは独立したSitesプロジェクトで管理し、親リポジトリでは `website/` をGitの対象外にしています。[公開・ダウンロード・動画再生の検証記録](docs/verification/2026-10-23-download-site.md)に、公開版の識別情報とファイル照合結果を記載しています。

`scripts/render-guide.py` は、macOSの `say`（Kyoko）、Pillow、ffmpeg / ffprobeを使って操作ガイドを作成します。実機から用意した `.build/tutorial/frames/` 内の画像など、ローカルの入力素材が必要です。これらの素材は配布リポジトリに含めていないため、リポジトリ単体では同じ動画を再生成できません。完成した動画・字幕・台本は配布サイトで公開しています。

## 初版の範囲

CleanShotを参考にした独立したアプリです。CleanShotのクラウド・独自ファイル形式との互換性はありません。カメラ合成、GIF出力、高度な動画編集、アプリの自動スクロール操作は未実装です。編集結果はPNG/JPEGとして保存し、注釈レイヤーの再保存形式には対応していません。
