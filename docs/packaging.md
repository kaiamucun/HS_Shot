# macOSインストーラの作成

```sh
./scripts/build-app.sh
# 生成したアプリで画面収録権限と撮影・編集・保存を確認する
./scripts/build-pkg.sh
```

`dist/HS-Shot-1.0.0.pkg` と同名の `.sha256` ファイルを作成します。バージョンはアプリの `Info.plist` から読み取ります。別の入力・出力先も指定できます。

```sh
./scripts/build-pkg.sh "/path/to/HS Shot.app" "/path/to/HS-Shot.pkg"
```

PKGには `/Applications/HS Shot.app` だけを含めます。インストールスクリプトはありません。別フォルダにある同じアプリのコピーへインストール先が変更されないよう、パッケージの再配置を無効にしています。既存のライブラリやユーザー設定はパッケージに含めません。

パッケージ作成時にはアプリを再ビルド・再署名しません。署名済みアプリをコピーし、PKGを展開して署名とアプリ内の全ファイルの一致を検証します。作成したMac固有のアクセス権・隔離属性などの拡張メタデータは同梱しません。生成時の検証では実際のインストールは行いません。

現在のビルドスクリプトが作成するアプリは開発用のローカル署名です。PKGは署名なしで、Appleの公証も行っていません。ダウンロード後の起動・インストールはmacOSのセキュリティ確認の対象になります。Developer IDによる署名・公証済みの製品として配布しないでください。

公開前には、実機で確認した最終アプリからPKGを生成し、次のコマンドで内容とハッシュを確認してください。

```sh
pkgutil --payload-files dist/HS-Shot-1.0.0.pkg
```

ハッシュ照合は `.sha256` とPKGがあるディレクトリで実行します。たとえば次の通りです。

```sh
cd dist
shasum -a 256 -c HS-Shot-1.0.0.pkg.sha256
```
