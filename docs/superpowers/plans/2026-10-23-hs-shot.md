# HS Shot Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for independent modules; root integrates and verifies.

**Goal:** Build a usable native macOS screen capture, annotation, OCR, recording and history app.

**Architecture:** SwiftUI workspace backed by AppKit utility windows and local files. Capture and editor modules have explicit independent interfaces; AppModel connects them.

**Tech Stack:** Swift 5 language mode, macOS 14+, AppKit, SwiftUI, Vision, ScreenCaptureKit, AVFoundation, SwiftPM.

**Spec:** `docs/superpowers/specs/2026-10-23-hs-shot-design.md`

## Global Constraints
- macOS 14以降。日本語UI。外部依存なし。
- ローカル保存。外部アップロードなし。
- キャンセル、処理中、失敗、保存完了を区別する。
- 原本を編集で上書きしない。
- エディタの公開APIは設計書の契約に合わせる。

## Review Focus
- 拒否された画面収録権限で処理中状態が残らない。
- Retina/マルチディスプレイで画像のピクセル寸法を維持する。
- 欠損履歴や不正JSONで起動時クラッシュしない。
- 秘匿と注釈が書き出したピクセルに確実に反映される。
- 録画停止時に完了するまで履歴に入れない。
