# 実画面キャプチャの通し検証

実施日: 2026-10-23（日本時間）

対象: `dist/HS Shot.app`、bundle ID `jp.huntersite.hsshot`、コミット `085b722` のバイナリ。許可後の再ビルド・差し替えなし。

| 確認項目 | 結果 |
| --- | --- |
| macOSの画面収録許可 | ユーザー本人のTouch ID認証後、HS Shotのスイッチonを確認 |
| 再起動後のアプリ内権限表示 | 「画面の撮影が許可されています」を確認 |
| 全画面の実撮影 | 撮影ボタンから3024×1964 PNGを生成、通常ライブラリへ保存 |
| 3秒タイマーでの実撮影 | 2枚目の3024×1964 PNGを生成 |
| 左下フローティングプレビュー | 撮影後も保持、画像クリックで対応する撮影画像をエディタへ表示 |
| 編集 | 日付表示へ切り抜き、赤い矢印、日本語「動作確認OK」を追加 |
| 履歴保存 | 原画像とは異なるIDで1094×154 PNGを保存、履歴件数2→3 |
| PNG書き出し | 保存ダイアログで `live-capture-edited.png` を保存 |
| 出力確認 | PNGをデコードして目視確認。履歴保存ファイルと書き出しファイルのSHA-256が一致 |
| 原本保持 | 編集前後で原画像のSHA-256が不変 |
| 再読込 | 編集済み項目を履歴から再度開き、矢印・日本語・寸法を確認 |
| 設定の後処理 | 確認用の3秒タイマーを「遅延なし」へ戻した |
