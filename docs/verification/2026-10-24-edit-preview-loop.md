# v1.1.1 — プレビューと編集の往復

## 変更

- プレビュー → 編集 → **完了（⌘S）** → 同じプレビュー、という動きへ変更。
- 同じプレビューから再開したとき、文字・矢印などの注釈、切り抜き・余白、Undo/Redoを保持。
- 原本から毎回描画するため、余白や注釈が重複しない。
- 同じセッションのエディタは1つ。編集時は対応するプレビューを隠し、閉じると元のパネルへ戻る。
- 保存失敗時はエディタを維持。別セッションへの誤更新を防ぐため、差し替えは対象プレビューだけに限定。
- × / ⌘Wは入力途中のテキストも下書きとして保持し、プレビューには最後の保存画像を表示。
- 編集状態はプレビューの保持期間内。明示的な閉鎖、最大4枚による退避、アプリ終了で終了。保存PNGはフラットな画像。

## 自動テストとレビュー

`swift test --build-system native`：64件、失敗0（2026-10-24）。

新規回帰テストで以下を確認：文書と注釈IDの再利用、反復保存時のPNG一致と寸法、Undo/Redo、独立したセッション、保存失敗と再試行、入力途中の確定、二重ウィンドウ防止、同一原本から新しいプレビューを作り直した後の隔離。

独立レビューで指摘された「退避された旧セッションから新しいプレビューへの誤更新」を修正し、再レビュー済み。実機で検出した⌘W時の未確定テキスト消失は、回帰テストで失敗を再現してから `windowWillClose` で入力を確定するよう修正。

## 実機検証（Apple Silicon / macOS）

専用の検証ライブラリと架空サンプル画像を使用。通常ライブラリ18ファイルのSHA-256は検証前後で一致。

1. 画面収録権限が許可された状態で、範囲選択のドラッグにより2300×1260pxを撮影。
2. 左下に210×150ポイント（Retina画像420×300px）のプレビューを確認。
3. 画像をクリックして編集。矢印1つ、日本語テキスト1つ、64pxの余白を追加。
4. 「完了」でエディタが閉じ、同じプレビューが編集画像に更新。
5. プレビューを開き直し、既存の「あとから調整」を「再編集できました」へ修正。既存の矢印の端点をドラッグして移動、Undo/Redoも確認。
6. ⌘Sで再びプレビューへ戻る。もう一度開いて変更せず完了しても2428×1388pxを維持し、前回PNGとバイト一致。
7. プレビューの「保存」から `HS-Shot-1.1.1-verified.png` を書き出し、ライブラリの最新PNGとSHA-256一致。

最終ビルドでは同じ寸法で範囲撮影を再実行し、未確定の「途中の編集も保持」を⌘W後に再表示できることを確認。さらに「完了後も再調整」へ変更してEnterを押さず⌘Sで保存、再び開いて同じ2個の注釈を確認。変更なしの再保存はPNGバイト一致し、プレビューからの `HS-Shot-1.1.1-final.png` 書き出しも最新PNGと一致しました。

ローカル証跡は `.build/verification-v111/`（公開対象外）。
