# HS Shot 1.3.0 操作ガイド更新の検証

## 対象

- ユーザー依頼：最新版の使い方動画に、自動保存 → アプリ終了 → 再起動 → 履歴から再編集する流れを入れて配布サイトへ反映。
- 使用アプリ：HS Shot 1.3.0 build 6。アプリ本体・既存PKGの変更なし。
- 公開先：https://hs-shot-download.kaiyamucun526.chatgpt.site/#guide
- 実際のアプリ画面の静止画と説明図に、音声・字幕を付けたガイド。連続した画面録画ではない。
- 撮影素材は操作説明用の架空サンプル。前回の1.3.0範囲撮影検証の原画像を、今回の隔離ライブラリに読み込んで操作した。

## 実機操作

1. 左下のプレビューから編集画面を開き、矢印と「ここを確認してください」の文字を追加。
2. 文字入力を確定せず、「完了」も押さず、画面下の「自動保存済み」を確認。
3. HS Shot メニューの「HS Shotを終了」を実行。プロセスが終了したことを確認。
4. 同じ隔離ライブラリで起動し、「編集中」「自動保存」と表示された履歴を選択して「編集」。
5. 文字をダブルクリックし「ここを修正しました」へ変更。同じ矢印の端点をドラッグし、向きを変更。
6. 「完了」で左下プレビューへ戻り、「保存」からPNGを書き出す。

終了前後の編集データで、文字・矢印のオブジェクトIDが一致し、文字内容と矢印の端点だけが変更されていることを確認。原本＋編集版の2件を維持。「完了」後は下書きフラグが外れた。

書き出しPNGは履歴の編集済みPNGとバイト一致。SHA-256: `ee7f8e4fd939baa0457b83ca7557f0992eb7cdb9d4b69e40a927de5d5168bee2`。

通常ライブラリ18ファイルのSHA-256一覧は開始前後で完全一致。隔離アプリを終了し、通常の17件のライブラリで起動し直した。
