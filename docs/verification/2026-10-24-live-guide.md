# HS Shot 実操作録画ガイドへの差し替え

## 依頼と成果物

静止画ガイドを、実際に操作した画面の録画へ差し替える依頼。録画中の実ポインターとクリック位置を残し、左下プレビュー → 注釈 → 自動保存 → アプリ終了 → 再起動 → 履歴から再編集 → 完了 → プレビューから保存の操作を収録した。

- アプリは既存の1.3.0 build6。本体・PKGの変更なし。
- 録画はScreenCaptureKitの連続フレーム。HS Shotと固定した説明用背景だけを含めるアプリフィルターを使用。
- `showsCursor` と `showMouseClicks` を有効化。ポインターを後から作成・補間していない。自動操作の都合で一部のポインターは操作間で飛ぶため、滑らかな移動とは表現しない。
- 左下プレビューを開くところから開始。初回インストール・画面収録許可・新規範囲撮影の映像はこの動画には含めず、サイト本文で案内。
- 架空サンプルのみを使う隔離ライブラリ。ユーザーの通常ライブラリ17件・18ファイルのSHA-256一覧は前後で一致。

## 実操作の確認

1. 左下プレビューから編集画面を開き、矢印をドラッグで追加。
2. 「ここを確認してください」を入力し、入力状態と「自動保存済み」を確認。
3. 「完了」を押さず、HS Shotメニューから終了。プロセス終了と保存済み下書きを確認。
4. 再起動し「編集中」「自動保存」の履歴を選び「編集」。
5. 同じ文字を「ここを修正しました」へ変更し、同じ矢印の端点を動かす。
6. 「完了」でプレビューへ戻り、右クリックの「保存」からPNGを書き出す。

終了前後で文字・矢印のオブジェクトIDが一致し、文字内容と矢印の端点が変化。履歴は原本＋編集版の2件を維持。書き出しPNGと履歴の編集済みPNGはバイト一致した。

書き出しPNG SHA-256: `8fb1e2d3de46284c32f00f1d6a1120871ef4f854b9feffbdaabbf4f6fffc383c`。

検証後は録画用アプリと背景を終了し、通常のライブラリでHS Shotを起動し直した。
